# Third-party code and data

The vendored Python package in `external/fastMRI_official/` is from the official fastMRI repository at commit `91f2df4711adbb6d643df1810f234e4abcf5881b`. Its original license and copyright notices are preserved in `external/fastMRI_official/LICENSE.md` and the source files. The upstream working tree was clean when copied. Only package source and project metadata are included, not example datasets or upstream Git history.

The fastMRI source-code license and the fastMRI dataset terms are different. MRI data must be obtained independently from https://fastmri.med.nyu.edu/ under the applicable data-use agreement. No data download links, original MRI measurements, image files, case-level results, or trained weights are included in this public archive.

No new software license for the authors' own code is selected by this archival operation. Public visibility alone is not a replacement for a license grant. Any future license should be chosen by the authors; the upstream fastMRI license applies only to its respective files.
